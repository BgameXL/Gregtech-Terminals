# Schematic Interface

The Schematic Interface copies and pastes multiblock structures.

## Copy

Shift + right-click a multiblock controller to copy every block that is part of the structure and save it as a named schematic for easy pasting later.

## Paste

Paste a saved schematic. The interface can connect to your ME network to pull the blocks it needs.

## Blueprint (Planned)

Being able to save builds/lines, is a planned feature and is not complete yet

## Requesting (planned)

Requesting blocks that are not in your inventory or network is a planned feature and is not complete yet.
